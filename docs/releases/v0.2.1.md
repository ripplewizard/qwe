# QWE 0.2.1

Status: Development release candidate; clean-source gate pass
Date: 2026-11-16

QWE 0.2.1 supersedes the unpublished 0.2.0 candidate and keeps the Stage 8,
Agent Execution, and Linux Bubblewrap sandbox scope.

## Changes

- Restored macOS ARM64 Clippy by isolating Linux-only sandbox imports,
  listeners, FD mounting, and Bubblewrap handshake code behind platform gates.
- Made Landlock error construction portable across supported build hosts.
- Fixed legacy worker reconciliation after the Pane-keyed storage migration.
- Updated release probes to derive the current schema and query Tasks through
  Pane ownership.

## Scope

Fedora Linux x86_64 remains the supported release target. Ubuntu 22.04/24.04
and Debian 12 x86_64 remain active development and sandbox-qualification
targets. aarch64, openEuler, Kylin, Rocky, public macOS distribution, VM/OCI
backends, Mesh, plugins, and untrusted multi-tenancy remain outside the current
scope.

The clean-source release gate, sandbox matrix, and archive checksum are
recorded only after a clean candidate commit is validated.
