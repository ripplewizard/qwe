# QWE 0.2.6

Status: Release candidate
Date: 2026-11-16

QWE 0.2.6 supersedes the unpublished 0.2.5 candidate.

## Changes

- The root README now provides a complete quick start for installation,
  service startup, Session Attach, multi-Pane composition, Agent capabilities,
  execution, and cleanup.
- Sandbox tests now cover the `openat2` path matrix, 10,000-run path fuzzing,
  Landlock ABI 1-255 masks, parser/sentinel failures, and feature-gated setup
  fault injection at every security boundary.
- `cargo-deny` enforces advisory, license, source, duplicate, and wildcard
  policy in CI.
- The hosted release workflow splits validation into diagnosable steps and
  serializes workspace tests before creating a GitHub Release.
- GitHub is the only release target; Gitee remains a source mirror.

## Scope

Fedora Linux x86_64 remains the supported release target. Ubuntu 22.04/24.04
and Debian 12 x86_64 remain active development and sandbox-qualification
targets. aarch64, openEuler, Kylin, Rocky, public macOS distribution, VM/OCI
backends, Mesh, plugins, and untrusted multi-tenancy remain outside the current
scope.
