# QWE 0.1.1

Status: Linux x86_64 stabilization release
Date: 2026-11-06

QWE 0.1.1 keeps the V0 runtime feature set and finishes the Linux release path.
It provides a clean-source Fedora package, repeatable core CI, a dedicated
Fedora release gate, checksums, and a published installation artifact.

## Included capabilities

- Durable terminal Sessions supervised by `qwed`.
- Detach and reattach with terminal snapshot, cursor, modes, and output-offset
  continuity.
- Worker and Task recovery after supervisor restart.
- Exclusive attachment, Lease ownership, and durable Task history.
- Linux cgroup v2 memory, CPU, and process-tree limits.
- Credentials delivered as inherited file descriptor 3 without placing secret
  bytes in argv, the environment, logs, or SQLite.
- Session, Task, and server teardown with terminal history retention.
- Checked native package installation, in-place reinstall, SQLite migration,
  installed systemd recovery, and TUI/job-control smoke coverage.

## Platform and scope

Fedora Linux x86_64 with a running systemd user manager is the supported V0
target. macOS ARM64 remains local/experimental and is not part of this public
binary release.

QWE remains a single-node runtime with one Pane and one TaskInstance per
Session. Mesh, remote scheduling, sandbox profiles, plugins, and multiple
TaskInstances per Session remain outside this release.

## Installation

Follow [Installing QWE](../../INSTALL.md) and verify the release asset with its
published SHA-256 before installation.
