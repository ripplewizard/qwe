# QWE 0.2.0

Status: Superseded before publication by QWE 0.2.1
Date: 2026-11-16

QWE 0.2.0 packages the Stage 8, Agent Execution, and Linux Bubblewrap sandbox
work merged on `dev`.

The candidate passed its local Linux release gate but failed macOS Clippy.
[QWE 0.2.1](v0.2.1.md) carries the cross-platform build repair and supersedes
this pre-publication candidate.

## Included capabilities

- Pane-targeted Attach, deterministic multi-Pane layout, durable layout state,
  split/close/focus/reorder, floating Panes, scrollback, and mouse copy.
- Fresh-process Agent Execution with stable command handles, bounded event
  replay, recovery, observer channels, capabilities, revocation, credentials,
  redaction, and merged PTY output.
- Linux `AGENT_EXEC` sandbox profiles and long-lived sandboxed Panes using
  Bubblewrap, Landlock defense in depth, named seccomp, restricted terminal
  output, audited input, profile refinement, and cgroup-scoped teardown.
- The current x86_64 qualification matrix covers Fedora SELinux, Ubuntu with
  its packaged AppArmor profile, and Debian.

## Platform and scope

Fedora Linux x86_64 remains the supported release target. Ubuntu 22.04/24.04
and Debian 12 x86_64 are active development and sandbox-qualification targets;
each becomes a public support claim only after its complete release gate.

aarch64, openEuler, Kylin, Rocky, public macOS distribution, containers as a
guaranteed sandbox host, VM/OCI backends, Mesh, plugins, and untrusted
multi-tenancy remain outside the current scope.
