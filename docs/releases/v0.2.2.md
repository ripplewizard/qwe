# QWE 0.2.2

Status: Development release candidate
Date: 2026-11-16

QWE 0.2.2 supersedes the unpublished 0.2.1 candidate and keeps the Stage 8,
Agent Execution, and Linux Bubblewrap sandbox scope.

## Changes

- Version tags now run the dedicated Fedora release gate and publish the
  archive plus SHA-256 as a GitHub Release using the workflow token.
- GitHub Actions use the current checkout, Python setup, and artifact upload
  actions.
- Ubuntu 24.04 AppArmor orphan-state polling has a wider bounded window after
  repeated Stage 10 qualification.

## Scope

Fedora Linux x86_64 remains the supported release target. Ubuntu 22.04/24.04
and Debian 12 x86_64 remain active development and sandbox-qualification
targets. aarch64, openEuler, Kylin, Rocky, public macOS distribution, VM/OCI
backends, Mesh, plugins, and untrusted multi-tenancy remain outside the current
scope.

Clean-source gate evidence and the published artifact URLs are recorded after
the tag workflow completes.
