# QWE 0.2.3

Status: Published; superseded by QWE 0.2.4 for portable checksum metadata
Date: 2026-11-16

QWE 0.2.3 supersedes the unpublished 0.2.2 candidate.

## Changes

- The hosted tag workflow invokes Cargo, rustfmt, Clippy, Python schema
  validation, and the packaging scripts directly, so it no longer requires a
  preinstalled `just` binary.
- Version tags publish the archive and SHA-256 through the GitHub workflow
  token. The complete dedicated Fedora gate remains a separate manual
  `workflow_dispatch`.
- Ubuntu 24.04 AppArmor orphan-state qualification has a wider bounded polling
  window.

## Scope

Fedora Linux x86_64 remains the supported release target. Ubuntu 22.04/24.04
and Debian 12 x86_64 remain active development and sandbox-qualification
targets. aarch64, openEuler, Kylin, Rocky, public macOS distribution, VM/OCI
backends, Mesh, plugins, and untrusted multi-tenancy remain outside the current
scope.
