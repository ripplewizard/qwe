# QWE 0.2.5

Status: Release candidate
Date: 2026-11-16

QWE 0.2.5 keeps the Stage 8, Agent Execution, and Linux Bubblewrap sandbox
scope and completes a round of documentation, adversarial testing, and
supply-chain hardening.

## Changes

- Root README now contains an end-to-end quick start covering installation,
  service startup, Attach, multi-Pane composition, Agent capabilities,
  execution, and cleanup.
- `openat2` path resolution has deterministic coverage for outside paths,
  symlinks, loops, missing paths, deep nesting, and non-directory roots.
- Landlock write masks are property-tested across ABI 1 through 255.
- `path_resolution` fuzz completed 10,000 runs against a symlink/loop/deep tree.
- Feature-gated fault injection verifies exit 125 and no target execution after
  NNP, ruleset creation, each path rule, dumpability hardening, and before exec.
- `cargo-deny` enforces advisories, licenses, registry/source policy, duplicate
  visibility, and wildcard visibility in CI.
- GitHub is the only release publication target; Gitee remains a source mirror.

## Scope

Fedora Linux x86_64 remains the supported release target. Ubuntu 22.04/24.04
and Debian 12 x86_64 remain active development and sandbox-qualification
targets. aarch64, openEuler, Kylin, Rocky, public macOS distribution, VM/OCI
backends, Mesh, plugins, and untrusted multi-tenancy remain outside the current
scope.

The clean-source release gate, CI results, archive URL, and hosted SHA-256 are
recorded after publication.
