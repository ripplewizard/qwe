# QWE 0.2.7

Status: Published Linux x86_64 release
Date: 2026-11-16

QWE 0.2.7 establishes the `dev` to `main` release flow.

## Changes

- GitHub `main` is the tested release branch; stable tags must be reachable
  from `main`.
- The tag workflow fetches `main` and rejects any stable tag that is not an
  ancestor of `main`.
- Development integration remains on `dev`; Gitee remains a source mirror only.
- The root README includes the end-to-end usage quick start.
- Sandbox hardening includes path fuzzing, ABI 1-255 tests, parser/sentinel
  checks, fault injection, and `cargo-deny`.

## Scope

Fedora Linux x86_64 remains the supported release target. Ubuntu 22.04/24.04
and Debian 12 x86_64 remain active development and sandbox-qualification
targets. aarch64, openEuler, Kylin, Rocky, public macOS distribution, VM/OCI
backends, Mesh, plugins, and untrusted multi-tenancy remain outside the current
scope.
