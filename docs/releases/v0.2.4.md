# QWE 0.2.4

Status: Published Linux x86_64 release
Date: 2026-11-16

QWE 0.2.4 supersedes the published 0.2.3 package because its `.sha256` asset
recorded a runner absolute path instead of the archive basename.

## Changes

- Release checksum files now contain the archive basename and can be consumed
  directly with `sha256sum --check`.
- Release notes include the exact hosted archive SHA-256 after publication.
- Hosted tag publication and the remaining sandbox scope are unchanged.

## Scope

Fedora Linux x86_64 remains the supported release target. Ubuntu 22.04/24.04
and Debian 12 x86_64 remain active development and sandbox-qualification
targets. aarch64, openEuler, Kylin, Rocky, public macOS distribution, VM/OCI
backends, Mesh, plugins, and untrusted multi-tenancy remain outside the current
scope.
