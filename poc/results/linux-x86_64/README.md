# Linux x86_64 Results

This directory is reserved for runs on the official Linux comparison platform.
Do not copy or infer scores from macOS results.

Run `just test-linux` on the Linux host. The generated environment record must
confirm Ubuntu 24.04 LTS, x86_64, at least 4 CPU cores, 8 GB RAM, and the
required toolchain versions before results are used for final scoring.
